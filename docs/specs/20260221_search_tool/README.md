# 背景

* マルチエージェントの仕組みの土台が実装された。
* ただし、各エージェントはモデル知識のみで動作しており、議論をする上で外部サイトから知見を得るという手段を持っていない。

# 解決方針

* 各エージェントに、Google Searchを行うツール、もしくは、RAGを提供し、議論をする際に外部サイトから情報を取得した上で、発言できるようにする。

* これは、特にCMOのような市場調査、顧客、ペルソナ等の情報収集の責任を負うエージェントには重要なツールとなる。

# 要件

* エージェントが外部のインターネットから情報を取得するRAGとなる関数を定義すること。
* チームの各メンバーを定義する際の tools 属性にて、利用するツールの関数名を規定することで、そのツールを利用できるようにすること。

# 相談事項

* ツールを定義する際、その関数をグローバル関数にするのは避けたい。従って、何かしらの名前空間を切って、ツールとなる関数を定義したい。しかし、設定ファイルで利用可能なツールを規定する際に全体パスで指定するのは冗長だと考える。その辺りをどのようにするのが良いかについては相談したい。
